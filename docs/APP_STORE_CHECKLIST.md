# App Store Checklist

这份清单用于把当前个人开发版推进到 App Store 提交版本。

## 必做

- 确认正式 bundle id 和 Apple Developer Team。
- 使用正式 App 图标和启动体验。
- 在 App 内加入隐私说明、数据源说明和投资免责声明。
- 准备 App Store Connect 隐私问卷。
- 准备 6.7 英寸、6.5 英寸或 Apple 要求尺寸的截图。
- 准备中文标题、副标题、关键词、描述、审核说明。
- 增加数据抓取失败的用户可见提示。
- 检查所有外部链接是否可打开。
- 确认 AI API Key 由用户自行输入，不内置开发者私钥。

## 建议增强

- 后台刷新或本地通知。
- 自选股搜索增强，补齐港股 stockId 自动解析。
- 事件详情页补充原文摘要和关键数字。
- 数据源健康检查。
- 首次启动引导：添加自选股、配置 AI、免责声明确认。

## 审核说明草稿

AI 投资日历是一款个人研究辅助工具，用于聚合公开宏观经济日程、上市公司公告和财报披露日期。App 不提供证券交易功能，不承诺收益，也不构成投资建议。AI 功能仅基于用户已添加的自选股和公开事件摘要生成日历研判，用户可选择不配置云端 AI API Key，App 会使用本地规则引擎运行。
