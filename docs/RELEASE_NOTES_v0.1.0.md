# AI 投资日历 v0.1.0

首个可用版本，面向个人投资者的 iPhone 投资日历。

## 亮点

- 以月历形式组织宏观经济事件和自选股重大事项。
- 内置 FOMC、CPI、中美主要宏观数据日程。
- 内置腾讯控股、宁德时代、紫金矿业、洛阳钼业、三美股份。
- 自动抓取 A 股公告、A 股财报预约披露、港股公告。
- 只展示更有信号的上市公司事项：重大合同、中标订单、定期报告、业绩预告、分红、重组、停复牌。
- 自动过滤低信号公告：担保、关联交易、普通会议材料、月报表等。
- 新增 AI 工作台：AI 研判、AI 联动图谱、AI 数据源状态。
- 支持本地规则兜底，也可配置 Gemini、DeepSeek、Kimi。
- API Key 保存到 iPhone Keychain，不进入源码。

## 数据源

- Federal Reserve FOMC calendar
- U.S. BLS release calendar
- 国家统计局主要统计信息发布日程
- 东方财富公告接口
- 东方财富预约披露
- HKEXnews

## 已验证

- SwiftUI 原生 iPhone App。
- 模拟器 Debug 构建通过。
- 真机 Debug 构建通过。
- 已成功安装到连接的 iPhone。

## 已知限制

- 当前是个人开发版，还没有 App Store 审核材料。
- 数据源来自公开网页和第三方公开接口，页面结构变化时需要维护。
- 云端 AI 需要用户自行配置 API Key；未配置时自动使用本地规则。
- 还没有后台刷新和推送通知。
